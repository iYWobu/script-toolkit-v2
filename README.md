# 脚本工具集 V2

畅读推广平台、巨量引擎、营销云数据助手系列油猴脚本集合，共 **12** 个脚本。

## 安装方法

1. 浏览器安装 [Tampermonkey](https://www.tampermonkey.net/) 扩展
2. 点击下方对应脚本的安装链接，Tampermonkey 会自动弹出安装页面
3. 点击「安装」即可使用
